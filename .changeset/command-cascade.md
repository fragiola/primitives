The command palette and the cascade select, natively in React, Vue and Angular, each in its own entry. `/command` (`Command`: `Root`, `Input`, `List`, `Item`, `Group`, `GroupLabel`, `Separator`, `Empty`, `Loading`): the APG combobox with a listbox that is always shown, the focus kept in the input (`aria-activedescendant`), built-in filtering by `commandScore` (substring and word prefix, an Item's `keywords`; `filter` replaces it, `null` turns it off), non-matching Items and empty Groups hidden, the best match highlighted as the text changes, Enter running the highlighted Item's `onSelect`, nested `pages` with Backspace on an empty input going back, `loading` with a busy list and the `Loading` and `Empty` live regions; a Command inside a Dialog opened by Ctrl/⌘+K is a documented composition, not a part. `/command-virtual` (`CommandVirtual.List`): the opt-in virtual list over an `items` array (10 000 items in the conformance suite), so `/command` bundles no `/virtual` code. `/cascade-select` (`CascadeSelect`: `Root`, `Trigger`, `Value`, `Portal`, `Positioner`, `Popup`, `Level`, `Item`, `ItemIndicator`): a select-only combobox whose popup holds one listbox per open level, ArrowRight and ArrowLeft opening and closing a level (swapped in RTL), typeahead per level, the value as the path of keys, `changeOnSelect` to choose a parent, levels opened on hover after a delay with Menu's safe triangle, a Field control submitting the path joined by `valueSeparator`. The toolkit gains `/command` (the scorer, `commandMatches`, `bestMatch`, `commandKeyTarget`) and `/cascade` (the levels of a path and `cascadeKeyAction`). Every other entry is unchanged.
