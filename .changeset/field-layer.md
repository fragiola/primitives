The Field layer to production, natively in React, Vue and Angular. Field's `validate` may be async (the latest run wins, a value already validated is not validated again), `Field.Error`'s `match` takes a function of the validity, and `validationMode` defaults to the enclosing Form's. New entries `/fieldset` (a `fieldset` named by its Legend, disabling every Field inside it, nested ones too) and `/form` (a native form that validates every field on submission, blocks it and focuses the first invalid field, shows server `errors` on the fields they name and reports `onClearErrors`). Every form control is a Field control: CheckboxGroup joins Checkbox, Select, Slider and Combobox, and the DatePicker and DateRangePicker gain form support (`name`, a visually hidden input with ISO dates, the range as `start/end`, `required`, `disabled`, `readOnly`, form reset). Slider gains `Label`, `Value` (an `<output>`), `format` and `locale` (Angular's value type is now `SliderRootValue`, `SliderValue` being the new directive). New entries `/direction` (`DirectionProvider` and `useDirection` / `injectDirection` / `provideDirection`, read by Tabs, Slider, Menu, Combobox's chips, the calendars and every positioned popup, with the computed direction as fallback) and `/render` (React's `useRender` and `mergeProps`, Vue's `renderPart`, `asProp` and `stateAttributes`, Angular's `dataValue` and `dataValues`). The toolkit's form entry gains `createFieldValidator`, the Form's errors and submission guard; a form bridge now focuses only the first invalid control's primitive; `getDirection` and `anchorFloating` take a provided direction.
