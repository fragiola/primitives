<Features columns={4}>
<Feature title="One spec, three frameworks">
Each component has one spec: its anatomy, API, states, keyboard and focus. React, Vue and Angular
each implement it natively, in their own idioms.
</Feature>
<Feature title="Accessible by default">
The WAI-ARIA Authoring Practices first, Base UI where they are silent: roles, keyboard, focus
trap, inert page, roving tab stop.
</Feature>
<Feature title="Styled by you">
No CSS, no icons, no text. State is data-\* attributes and ARIA, and every element names its part
with `data-primitives-part`.
</Feature>
<Feature title="Only what you import">
One entry per component and per toolkit mechanism, ESM only, no side effects: an app that uses
two components ships those two.
</Feature>
</Features>

<Section title="What it never ships">
<Pills strike items={["CSS", "Icons", "Text", "Accessible names", "A design system"]} />

The primitives render your children and nothing else. The examples are styled with Tailwind
recipes keyed on the part and state attributes, in five themes that change shape, not only colour.
</Section>
