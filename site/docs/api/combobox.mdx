A text input that filters a popup list, for choosing **one** value or **several** (WAI-ARIA APG
[combobox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) with a `listbox` popup:
list autocomplete without automatic selection). It has the parts of Fragiola UI's combobox, on
Base UI's behaviour. A list chosen from a button, with no text, is a [Select](/docs/api/select).

## Behaviour

These are decided (D10): the APG allows them or says nothing about them.

- **It filters**: given `items`, the combobox filters them with the input's text and gives the
  List the matching ones, through a render function. The default filter is a locale-aware
  "contains" that ignores case and accents (`sao` finds "São Paulo"); `filter` replaces it, `null`
  turns it off, `limit` caps the list. Without `items`, the consumer filters and renders the Items.
- **Values are items**: a string or any object, compared with `isItemEqualToValue` and turned into
  text with `itemToStringLabel` (the input's text, the filter) and `itemToStringValue` (the form).
- **`multiple`** keeps a list of values, shown as chips: choosing an item adds it, or removes it
  when it is already chosen.
- **Escape resets the text**: closing the list without a choice resets the input's text to the
  selected item's label (`""` with none, or with `multiple`); Escape on the closed list clears the
  text and the value.
- **A press on the input opens the list** (reason `input-press`), on the selected item.
- **Focus**: DOM focus stays on the input; the highlighted item is announced with
  `aria-activedescendant`. Typing highlights nothing until the user navigates; ArrowDown past the
  last item returns to the input.
- **Forms**: hidden inputs carry `name` and `itemToStringValue(value)` (one per value with
  `multiple`), and a visually hidden input carries `required`. A form reset returns an
  uncontrolled combobox to `defaultValue`. In a [Field](/docs/api/field), the Input takes the
  field's ids and states.
- **Lifecycle**: `onOpenChange` is called before the change (`details.cancel()` keeps it as it
  is, [change details](/docs/concepts/primitive-contract)), `onOpenChangeComplete(open)` reports
  the end of each transition, the actions `close()` and `unmount()` act from code, and the
  Portal's `keepMounted` keeps the Positioner in the page while closed (`hidden`, `data-closed`).
- **Long and loaded lists**: for thousands of items, or items loaded page by page, use
  [ComboboxVirtual](/docs/api/combobox-virtual): **ComboboxVirtual.List** (`/combobox-virtual`)
  replaces the List and renders only the matching items in view, with the same keys over every
  match. Its pages can come from a loader through the [async list](/docs/api/async-list)
  (`loading`, `onLoadMore`). It is opt-in: this entry ships no virtualizer.

## Anatomy

| part | element | `data-primitives-part` | role |
| --- | --- | --- | --- |
| Root | none | | holds the state; renders the hidden inputs |
| InputGroup | `div` | `combobox-input-group` | holds the Input and its buttons, and anchors the list |
| Input | `input` | `combobox-input` | the `combobox`; keeps DOM focus |
| Trigger | `button` | `combobox-trigger` | toggles the list; not in the tab order |
| Clear | `button` | `combobox-clear` | clears the value and the text; rendered only while there is a value |
| Chips | `div` | `combobox-chips` | `multiple`: holds the chips and the Input; anchors the list |
| Chip | `div` | `combobox-chip` | one per value |
| ChipRemove | `button` | `combobox-chip-remove` | removes its chip's value |
| Value | none | | renders the value: its label, or a render function of it |
| Status | `div` | `combobox-status` | a polite live region for the consumer's text |
| Portal | none | | moves the Positioner to the end of `body` |
| Positioner | `div` | `combobox-positioner` | places the popup under the anchor |
| Popup | `div` | `combobox-popup` | the floating container |
| Empty | `div` | `combobox-empty` | a polite live region; its children show only while the list is empty |
| List | `div` | `combobox-list` | the `listbox` |
| Group | `div` | `combobox-group` | a `group` of items |
| GroupLabel | `div` | `combobox-group-label` | names its Group |
| Separator | `div` | `combobox-separator` | between groups |
| Item | `div` | `combobox-item` | an `option` |
| ItemIndicator | `span` | `combobox-item-indicator` | rendered only while its item is selected |
| (hidden inputs) | `input` | `combobox-hidden-input` | what the form submits and validates |

## Usage

<Framework name="react">

```tsx
import { Combobox } from "@fragiola/primitives-react/combobox";

const FRUITS = [
    { value: "apple", label: "Apple" },
    { value: "banana", label: "Banana" },
];

<Combobox.Root items={FRUITS} name="fruit">
    <label htmlFor="fruit">Fruit</label>
    <Combobox.InputGroup>
        <Combobox.Input id="fruit" />
        <Combobox.Clear aria-label="Clear fruit">×</Combobox.Clear>
        <Combobox.Trigger aria-label="Show fruits">▾</Combobox.Trigger>
    </Combobox.InputGroup>
    <Combobox.Portal>
        <Combobox.Positioner sideOffset={4}>
            <Combobox.Popup>
                <Combobox.Empty>No fruit found.</Combobox.Empty>
                <Combobox.List>
                    {(fruit: (typeof FRUITS)[number]) => (
                        <Combobox.Item key={fruit.value} value={fruit}>
                            {fruit.label}
                        </Combobox.Item>
                    )}
                </Combobox.List>
            </Combobox.Popup>
        </Combobox.Positioner>
    </Combobox.Portal>
</Combobox.Root>;
```

With `multiple`, the Chips hold a `Combobox.Value` whose render function gets the values and
renders a Chip per value, then the Input.

</Framework>

<Framework name="vue">

```vue
<template>
    <Combobox.Root v-model:value="fruit" :items="FRUITS" name="fruit">
        <Combobox.InputGroup>
            <Combobox.Input id="fruit" />
        </Combobox.InputGroup>
        <Combobox.Portal>
            <Combobox.Positioner :side-offset="4">
                <Combobox.Popup>
                    <Combobox.Empty>No fruit found.</Combobox.Empty>
                    <Combobox.List v-slot="{ entry }: { entry: (typeof FRUITS)[number] }">
                        <Combobox.Item :key="entry.value" :value="entry">{{ entry.label }}</Combobox.Item>
                    </Combobox.List>
                </Combobox.Popup>
            </Combobox.Positioner>
        </Combobox.Portal>
    </Combobox.Root>
</template>
```

The List's default scoped slot gets `{ entry, index }`; the Value's, `{ value }`. The slot's
annotation names the consumer's item type, with no cast (`v-slot="{ value }: { value: Country[] }"`
with `multiple`), as React's render function infers it from its parameter.

</Framework>

<Framework name="angular">

```ts
@Component({
    imports: [ComboboxRoot, ComboboxInputGroup, ComboboxInput, ComboboxPortal, ComboboxPositioner, ComboboxPopup, ComboboxEmpty, ComboboxList, ComboboxItem],
    template: `
        <ng-container comboboxRoot [items]="fruits" name="fruit">
            <div comboboxInputGroup><input comboboxInput id="fruit" /></div>
            <ng-container *comboboxPortal>
                <div comboboxPositioner [sideOffset]="4">
                    <div comboboxPopup>
                        <div comboboxEmpty>No fruit found.</div>
                        <div comboboxList #list="comboboxList">
                            @for (fruit of list.entries(); track fruit.value) {
                                <div comboboxItem [value]="fruit">{{ fruit.label }}</div>
                            }
                        </div>
                    </div>
                </div>
            </ng-container>
        </ng-container>
    `,
})
export class FruitSearch {
    protected readonly fruits = FRUITS;
}
```

There is no Value directive: the Root's `value()` signal, read through `exportAs`
(`#combobox="comboboxRoot"`), gives the chips. `injectCombobox()` gives a child component the
state, `choose` and `clear`.

</Framework>

## Props

Every part also takes what the [primitive contract](/docs/concepts/primitive-contract) gives:
`render` (Vue: `as` and the `render` slot), a class and a style, a ref, and any attribute, which
it forwards. The names below are React's; Vue binds them the same way (`v-model:value`,
`v-model:input-value`, `v-model:open`), and Angular as inputs and outputs (`[(value)]`,
`[(inputValue)]`, `[(open)]`, `(valueChangeDetails)`).

### Root

| prop | type | default | description |
| --- | --- | --- | --- |
| `items` | `(Item \| { items: Item[] })[]` | | the items, or groups of items: the combobox filters them |
| `filter` | `(item, query, itemToString) => boolean \| null` | locale-aware "contains" | whether an item matches; `null`: no filtering. Vue and Angular type it over the consumer's own item (`ItemFilter<Country>`, `containsFilter<Country>()` bind with no cast), as `isItemEqualToValue` and the `itemToString*` callbacks |
| `limit` | `number` | `-1` | the most items the List renders |
| `locale` | `string` | the document's | the collator's locale |
| `multiple` | `boolean` | `false` | a list of values, with chips |
| `value` | `Item \| null`, or `Item[]` | | the value, controlled |
| `defaultValue` | `Item \| null`, or `Item[]` | `null`, or `[]` | the initial value, uncontrolled |
| `onValueChange` | `(value, details: { reason }) => void` | | every change (`item-press`, `clear-press`, `chip-remove-press`, `escape-key`, `none`) |
| `inputValue` | `string` | | the input's text, controlled |
| `defaultInputValue` | `string` | the default value's label | the initial text |
| `onInputValueChange` | `(text: string, details: { reason }) => void` | | every text change (`input-change`, `input-clear`, `item-press`, `none`) |
| `isItemEqualToValue` | `(item, value) => boolean` | `Object.is` | whether an item is a value |
| `itemToStringLabel` | `(item) => string` | an object's `label`, else its `value`, else the item | an item's text |
| `itemToStringValue` | `(item) => string` | an object's `value`, else the item | an item's form value |
| `name` | `string` | | the hidden inputs' name (a field's wins) |
| `required` | `boolean` | `false` | the form cannot submit with no value |
| `disabled` | `boolean` | `false` | disables the input and its buttons |

## Keyboard

| key | action |
| --- | --- |
| typing | filters and opens; nothing is highlighted yet |
| ArrowDown / ArrowUp | closed: opens on the selected item, else the first (last); open: the next (previous) item, then back to the input |
| Alt+ArrowDown / Alt+ArrowUp | opens without highlighting / closes |
| Enter | chooses the highlighted item; never submits a form while the list is open |
| Escape | open: closes and resets the text; closed: clears the text and the value |
| Tab | closes without choosing and moves on |
| Backspace | `multiple`, empty input: removes the last value |
| ArrowLeft (ArrowRight in RTL) | `multiple`, caret at the start: focuses the last chip; on a chip, the arrows move between chips and back to the input, Backspace and Delete remove it |
