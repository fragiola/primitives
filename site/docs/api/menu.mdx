description: A menu of actions opened by a button, with submenus, roving focus and typeahead, non-modal by default, following the APG menu button pattern in each framework.

A list of actions opened by a button, with nested submenus. The highlighted item is the focused
one (roving focus), typing jumps to an item, and each level is a layer. It follows the WAI-ARIA
APG [menu button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/): **non-modal by
default**, with a `modal` option that locks the page's scroll and blocks the pointer outside.
Its items may be actions, checkbox items and radio items. A menu opened at the pointer from an
area is a [ContextMenu](/docs/api/context-menu); a bar of menus is a [Menubar](/docs/api/menubar),
whose items are Menu Triggers.

## Behaviour

- **Open**: ArrowDown, Enter or Space on the Trigger opens it on the first item, ArrowUp on the
  last; a press opens it with the popup focused and no item highlighted.
- **Inside**: ArrowDown and ArrowUp move (wrapping with `loopFocus`), Home and End jump, a typed
  character moves to the next item that starts with it. A disabled item stays focusable but is
  never activated (APG). Hovering an item highlights it.
- **Activate**: Enter, Space or a click fires the item's `click`, then closes every level
  (reason `item-press`) and focuses the trigger.
- **Checkbox and radio items**: Space toggles a CheckboxItem (checks a RadioItem) and keeps the
  menu open; Enter toggles it and closes every level (APG); a click toggles it and closes only
  with `closeOnClick` (default `false`, Base UI). Each change reports `onCheckedChange` or the
  RadioGroup's `onValueChange` with the reason `item-press`. An indicator renders only while its
  item is checked, unless `keepMounted`.
- **Submenus**: ArrowRight (ArrowLeft in RTL), Enter or Space on a SubmenuTrigger opens its
  submenu on its first item, hovering it opens it after `delay`; ArrowLeft closes it. While the
  pointer travels to an open submenu, crossing other items does not close it (a safe area).
- **Close**: Escape closes one level (`escape-key`), focus back on its trigger. Tab closes every
  level (`focus-out`) and moves on from the trigger. A press outside closes them all
  (`outside-press`).
- **Modal** (`modal`): while open, the page does not scroll and a press outside reaches no
  element of the page: it only closes the menu, focus back on the trigger. The keyboard is
  unchanged.
- **Layers**: each level is a layer of the [nested overlay tree](/docs/guides/nested-overlays): a
  submenu is a child of its menu, and a menu opened from a popover or a dialog is that overlay's
  child, so a press inside the parent closes the menu only.
- **Detached triggers**: Triggers anywhere in the page open the same Root through a `handle`,
  each with a `payload` ([detached triggers](/docs/guides/detached-triggers)). The menu anchors to
  the active trigger and its popup is labelled by it; a press on another trigger while open moves
  the menu there (it stays open, with the new payload).
- **Lifecycle**: `onOpenChangeComplete(open)` reports the end of each transition, the actions
  `close()` and `unmount()` act from code, and the Portal's `keepMounted` keeps the Positioner in
  the page while closed (`hidden`, `data-closed`).

## Anatomy

| part | element | `data-primitives-part` | role |
| --- | --- | --- | --- |
| Root | none | | holds the state of one menu level |
| Trigger | `button` | `menu-trigger` | opens the menu |
| Portal | none | | moves the Positioner to the end of `body` |
| Positioner | `div` | `menu-positioner` | places a level next to its trigger |
| Popup | `div` | `menu-popup` | the menu |
| Item | `div` | `menu-item` | an action |
| Separator | `div` | `menu-separator` | separates items |
| Group | `div` | `menu-group` | groups items under a label |
| GroupLabel | `div` | `menu-group-label` | names its group |
| CheckboxItem | `div` | `menu-checkbox-item` | an item that toggles a setting |
| CheckboxItemIndicator | `span` | `menu-checkbox-item-indicator` | inside a CheckboxItem, rendered while it is checked |
| RadioGroup | `div` | `menu-radio-group` | holds the value of its radio items |
| RadioItem | `div` | `menu-radio-item` | an item of a set where one is checked |
| RadioItemIndicator | `span` | `menu-radio-item-indicator` | inside a RadioItem, rendered while it is checked |
| SubmenuRoot | none | | a nested level |
| SubmenuTrigger | `div` | `menu-submenu-trigger` | the item that opens a submenu |

## Usage

<Framework name="react">

```tsx
import { Menu } from "@fragiola/primitives-react/menu";

<Menu.Root>
    <Menu.Trigger>File</Menu.Trigger>
    <Menu.Portal>
        <Menu.Positioner sideOffset={4}>
            <Menu.Popup>
                <Menu.Item onClick={() => create()}>New file</Menu.Item>
                <Menu.SubmenuRoot>
                    <Menu.SubmenuTrigger>Share</Menu.SubmenuTrigger>
                    <Menu.Portal>
                        <Menu.Positioner>
                            <Menu.Popup>
                                <Menu.Item onClick={() => share("email")}>Email</Menu.Item>
                            </Menu.Popup>
                        </Menu.Positioner>
                    </Menu.Portal>
                </Menu.SubmenuRoot>
                <Menu.Separator />
                <Menu.Item disabled>Export</Menu.Item>
            </Menu.Popup>
        </Menu.Positioner>
    </Menu.Portal>
</Menu.Root>;
```

Checkbox and radio items:

```tsx
<Menu.Popup>
    <Menu.CheckboxItem checked={toolbar} onCheckedChange={setToolbar}>
        <Menu.CheckboxItemIndicator>✓</Menu.CheckboxItemIndicator>
        Show toolbar
    </Menu.CheckboxItem>
    <Menu.Group>
        <Menu.GroupLabel>Sort by</Menu.GroupLabel>
        <Menu.RadioGroup value={sort} onValueChange={setSort}>
            <Menu.RadioItem value="name">
                <Menu.RadioItemIndicator>•</Menu.RadioItemIndicator>
                Name
            </Menu.RadioItem>
            <Menu.RadioItem value="date">
                <Menu.RadioItemIndicator>•</Menu.RadioItemIndicator>
                Date
            </Menu.RadioItem>
        </Menu.RadioGroup>
    </Menu.Group>
</Menu.Popup>;
```

</Framework>

Checkbox and radio items: `<Menu.CheckboxItem v-model:checked="toolbar">` and
`<Menu.RadioGroup v-model:value="sort">` around `<Menu.RadioItem value="name">`, each with its
`Menu.CheckboxItemIndicator` or `Menu.RadioItemIndicator`.

</Framework>

<Framework name="angular">

```ts
@Component({
    imports: [MenuRoot, MenuTrigger, MenuPortal, MenuPositioner, MenuPopup, MenuItem, MenuSeparator, MenuSubmenuTrigger],
    template: `
        <ng-container menuRoot>
            <button menuTrigger>File</button>
            <ng-container *menuPortal>
                <div menuPositioner [sideOffset]="4">
                    <div menuPopup>
                        <div menuItem (click)="create()">New file</div>
                        <ng-container menuSubmenuRoot>
                            <div menuSubmenuTrigger>Share</div>
                            <ng-container *menuPortal>
                                <div menuPositioner>
                                    <div menuPopup>
                                        <div menuItem (click)="share('email')">Email</div>
                                    </div>
                                </div>
                            </ng-container>
                        </ng-container>
                        <div menuSeparator></div>
                        <div menuItem disabled>Export</div>
                    </div>
                </div>
            </ng-container>
        </ng-container>
    `,
})
export class FileMenu {}
```

Checkbox and radio items: `<div menuCheckboxItem [(checked)]="toolbar">` and
`<div menuRadioGroup [(value)]="sort">` around `<div menuRadioItem value="name">`; their
indicators are structural (`<span *menuCheckboxItemIndicator>✓</span>`, rendered while checked;
`*menuRadioItemIndicator="{ keepMounted: true }"` keeps one).

`[menuRoot]` and `[menuSubmenuRoot]` are one directive, `MenuRoot`. The entry also exports its
lower layer, which ContextMenu's directives extend: `MenuRootBase`, `MenuComponent`,
`MENU_SUBMENU`, `SafeArea`, `indicatorOptions` and the checkable items' state types. `injectMenu()` gives a child
component its level's state.

</Framework>

## Props

Every part also takes what the [primitive contract](/docs/concepts/primitive-contract) gives:
`render` (Vue: `as` and the `render` slot), a class and a style, a ref, and any attribute, which
it forwards. The names below are React's; Vue binds them the same way (`v-model:open`,
`@open-change`, `:loop-focus`), and Angular as inputs and outputs (`[(open)]`,
`(openChangeDetails)`, `[loopFocus]`). An item's activation is its `click` event (`onClick`,
`@click`, `(click)`). A CheckboxItem binds `v-model:checked` (`@checked-change`) in Vue and
`[(checked)]` in Angular, whose `(checkedChangeDetails)` emits `{ value, details }`; a RadioGroup
`v-model:value` and `[(value)]`, `(valueChangeDetails)`.

### Root

| prop | type | default | description |
| --- | --- | --- | --- |
| `open` | `boolean` | | the open state, controlled |
| `defaultOpen` | `boolean` | `false` | the initial open state, uncontrolled |
| `onOpenChange` | `(open: boolean, details: OpenChangeDetails) => void` | | every change, with its reason (`trigger-press`, `list-navigation`, `item-press`, `escape-key`, `outside-press`, `focus-out`); called before the change, `details.cancel()` stops it |
| `onOpenChangeComplete` | `(open: boolean) => void` | | once an opening or a closing has finished its transitions (not on the first render, nor for an exit a reopening interrupted) |
| `actionsRef` (react) | `{ current: OverlayActions \| null }` | | receives `close()` (reason `imperative-action`) and `unmount()` (ends an exit now); Vue exposes them on the Root's template ref, Angular as the root directive's methods |
| `handle` | `MenuHandle<Payload>` | | connects Triggers rendered outside the Root ([detached triggers](/docs/guides/detached-triggers)) |
| `triggerId` | `string \| null` | | the active trigger's id, controlled together with `open` |
| `defaultTriggerId` | `string \| null` | `null` | the initial active trigger, uncontrolled |
| `loopFocus` | `boolean` | `true` | the arrow keys wrap at the ends |
| `modal` | `boolean` | `false` | locks the page's scroll and blocks the pointer outside while open |

### Trigger

| prop | type | default | description |
| --- | --- | --- | --- |
| `disabled` | `boolean` | `false` | a disabled trigger opens nothing |
| `handle` | `MenuHandle<Payload>` | | the handle of a Root this Trigger opens from anywhere, outside it |
| `payload` | `Payload` | | what the Root's content receives while this Trigger is the active one |
| `id` | `string` | generated | the Trigger's id: `triggerId` and the handle's `open(id)` name it |

### Portal

| prop | type | default | description |
| --- | --- | --- | --- |
| `container` (react, vue) | `Element` | `document.body` | where the Positioner goes |
| `keepMounted` (react, vue) | `boolean` | `false` | keep the content rendered while closed (before the first opening and after an exit), `hidden` and `data-closed`; reopening shows the same elements |
| `options` (angular) | `Element \| { container?, keepMounted? }` | `{}` | the same two options: `*menuPortal="{ keepMounted: true }"`, or `*menuPortal="element"` for a container alone |

### Positioner

| prop | type | default | description |
| --- | --- | --- | --- |

| `align` | `"start" \| "center" \| "end"` | `"start"` | the alignment along that side |
| `sideOffset` | `number` | `0` | the distance from the trigger, in px |

| `collisionPadding` | `number` | `8` | the space kept from the viewport's edges, in px |

## Keyboard

| key | action |
| --- | --- |
| ArrowDown, Enter, Space on the Trigger | opens on the first item |
| ArrowUp on the Trigger | opens on the last item |
| ArrowDown, ArrowUp | the next or previous item (wrapping with `loopFocus`) |
| Home, End | the first or last item |
| a character | the next item that starts with the typed text |
| Enter, Space | activates the item, closing every level |
| Space on a CheckboxItem or RadioItem | toggles or checks it; the menu stays open |
| Enter on a CheckboxItem or RadioItem | toggles or checks it, closing every level |
| ArrowRight (ArrowLeft in RTL) on a SubmenuTrigger | opens its submenu on its first item |
| ArrowLeft (ArrowRight in RTL) in a submenu | closes it |
| Escape | closes the current level |
| Tab, Shift+Tab | closes every level and moves on from the trigger |
