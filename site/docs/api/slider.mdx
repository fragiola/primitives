Choose a number within bounds, or a range with several thumbs (WAI-ARIA APG
[slider](https://www.w3.org/WAI/ARIA/apg/patterns/slider/) and
[multi-thumb slider](https://www.w3.org/WAI/ARIA/apg/patterns/slider-multithumb/)). It works in a
native `<form>`: each thumb submits its value. A Label names it and a Value shows the value,
formatted with `Intl.NumberFormat` when you pass `format`.

<Example id="slider" />

## Behaviour

- **Value**: a number, or an array of numbers for several thumbs (sorted); the type of
  `defaultValue` (or `value`) decides. Values snap to `min + n × step` and stay in `[min, max]`;
  thumbs never cross, and stay `minStepsBetweenValues × step` apart.
- **Pointer**: a press on the Control moves the nearest thumb there (reason `track-press`),
  focuses it and starts a drag; the drag follows the pointer outside the Control until it is
  released (reason `drag`, `data-dragging` meanwhile). `touch-action: none` keeps a touch drag
  from scrolling.
- **Commit**: `onValueCommit` once a drag ends, or after a key changed the value.
- **Label**: names the Root and every Thumb that has no `aria-label` or `aria-labelledby` of its
  own; a press on it focuses the first Thumb. Inside a [Field](/docs/api/field), the Field's
  Label names the slider instead: use one or the other.
- **Value**: an `output` whose `for` lists the Thumbs' ids. It shows the formatted values, joined
  with `" – "` for several thumbs, or the content you give it. `aria-live="off"`: a drag would
  announce every step.
- **Format**: with `format` (`Intl.NumberFormatOptions`, in `locale`), the Value and each Thumb's
  `aria-valuetext` use the formatted value; `getAriaValueText` wins over it. Without `format`, the
  Value shows the plain numbers and the Thumbs have no `aria-valuetext` of their own. Without
  `locale`, the runtime's default: a page rendered on a server passes `locale`, so the server
  formats as the browser does.
- **RTL**: horizontal sliders run right to left (`min` at the right, the arrows swap), in the
  direction of a [DirectionProvider](/docs/api/direction), else the computed one.
- **Forms**: one hidden input per thumb submits `name=value`, in order. Inside a
  [Field](/docs/api/field), its `validate` receives the number (or numbers); it cannot block a
  native submission (the inputs are `type="hidden"`), a [Form](/docs/api/form) does.

## Anatomy

| part | element | `data-primitives-part` | role |
| --- | --- | --- | --- |
| Root | `div` | `slider-root` | the `group`; holds the state |
| Label | `div` | `slider-label` | names the Root and its Thumbs |
| Value | `output` | `slider-value` | shows the formatted value(s) |
| Control | `div` | `slider-control` | the interactive area |
| Track | `div` | `slider-track` | the rail |
| Indicator | `div` | `slider-indicator` | the filled part: from `min` to the value, or between two thumbs |
| Thumb | `div` | `slider-thumb` | a `slider`; one per value |
| (hidden input) | `input type="hidden"` | `slider-input` | one per value: what the form submits |

## Usage

<Framework name="react">

```tsx
import { Slider } from "@fragiola/primitives-react/slider";

<Slider.Root
    defaultValue={[20, 80]}
    minStepsBetweenValues={10}
    name="price"
    format={{ style: "currency", currency: "EUR", maximumFractionDigits: 0 }}
    locale="de-DE"
>
    <Slider.Label>Price</Slider.Label>
    <Slider.Value />
    <Slider.Control>
        <Slider.Track>
            <Slider.Indicator />
        </Slider.Track>
        <Slider.Thumb aria-label="Minimum price" />
        <Slider.Thumb aria-label="Maximum price" />
    </Slider.Control>
</Slider.Root>;
```

</Framework>

<Framework name="vue">

```vue
<template>
    <Slider.Root v-model:value="volume" :min="0" :max="1" :step="0.01" :format="{ style: 'percent' }" locale="en-US">
        <Slider.Label>Volume</Slider.Label>
        <Slider.Value v-slot="{ formattedValues }">{{ formattedValues[0] }}</Slider.Value>
        <Slider.Control>
            <Slider.Track><Slider.Indicator /></Slider.Track>
            <Slider.Thumb />
        </Slider.Control>
    </Slider.Root>
</template>
```

</Framework>

<Framework name="angular">

```ts
@Component({
    imports: [SliderRoot, SliderLabel, SliderValue, SliderControl, SliderTrack, SliderIndicator, SliderThumb],
    template: `
        <div sliderRoot [(value)]="volume" [format]="percent" locale="en-US">
            <div sliderLabel>Volume</div>
            <output sliderValue></output>
            <div sliderControl>
                <div sliderTrack><div sliderIndicator></div></div>
                <div sliderThumb></div>
            </div>
        </div>
    `,
})
export class Volume {
    protected readonly percent: Intl.NumberFormatOptions = { style: "unit", unit: "percent" };
    protected readonly volume = signal<SliderRootValue>(50);
}
```

The value's type is `SliderRootValue` (`number | readonly number[]`); it was named `SliderValue`
before the Value part took that name. `<output sliderValue #value="sliderValue">` reads
`value.formattedValues()` and `value.values()` for content of your own.

</Framework>

## Props

Every part also takes what the [primitive contract](/docs/concepts/primitive-contract) gives:
`render` (Vue: `as` and the `render` slot), a class and a style, a ref, and any attribute, which
it forwards. The names below are React's; Vue binds them the same way (`v-model:value`,
`@value-commit`), and Angular as inputs and outputs (`[(value)]`, `(valueCommit)`).

### Root

| prop | type | default | description |
| --- | --- | --- | --- |
| `value` | `number \| number[]` | | the value, controlled |
| `defaultValue` | `number \| number[]` | `min` | the initial value, uncontrolled |
| `onValueChange` | `(value, details: { reason }) => void` | | every change (`keyboard`, `track-press`, `drag`) |
| `onValueCommit` | `(value, details: { reason }) => void` | | once a drag ends, or after a key |
| `min` | `number` | `0` | the lower bound |
| `max` | `number` | `100` | the upper bound |
| `step` | `number` | `1` | the step of the arrows and the snapping |
| `largeStep` | `number` | `10` | the step of Page Up, Page Down and Shift+Arrow |
| `minStepsBetweenValues` | `number` | `0` | the smallest distance between two thumbs, in steps |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | the axis |
| `disabled` | `boolean` | `false` | ignores the pointer and the keys |
| `name` | `string` | | the form name of the hidden inputs (a Field's wins) |
| `format` | `Intl.NumberFormatOptions` | | how the Value and each Thumb's `aria-valuetext` write the values |
| `locale` | `string` | the runtime's | the locale of `format` (a BCP 47 tag) |

### Label

| prop | type | default | description |
| --- | --- | --- | --- |
| `id` | `string` | generated | the id the Root's and the Thumbs' `aria-labelledby` point at |

### Value

No props of its own. Its children replace the formatted values: a function
`(formattedValues, values) => ReactNode` in React, the default scoped slot
`{ formattedValues, values }` in Vue, the directive's `formattedValues()` and `values()` signals
in Angular.

### Control

No props of its own.

### Track

No props of its own.

### Indicator

No props of its own.

### Thumb

| prop | type | default | description |
| --- | --- | --- | --- |
| `index` | `number` | its order | the index of its value |
| `getAriaValueText` | `(value: number, index: number) => string` | | the `aria-valuetext`; it wins over `format` |
| `disabled` | `boolean` | `false` | this thumb only |
| `id` | `string` | generated | the thumb's id, in the Value's `for` |

A thumb's accessible name comes from the consumer (`aria-label`, `aria-labelledby`), or the
Label.

## State and part attributes

| part | attributes |
| --- | --- |
| Root | `role="group"`, `aria-labelledby` (the Label, while one is rendered), `data-orientation`, `data-disabled`, `data-dragging`; in a Field, the field's states |
| Label | `id`, `data-orientation`, `data-disabled` |
| Value | `for` (the Thumbs' ids, in value order), `aria-live="off"`, `data-orientation`, `data-disabled` |
| Control, Track | `data-orientation`, `data-disabled`, `data-dragging` |
| Indicator | `data-orientation`; structural inline style (`inset-inline-start` and `inline-size` in %, or the block ones) |
| Thumb | `role="slider"`, `id`, `tabindex="0"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax` (the bounds it can reach), `aria-valuetext`, `aria-labelledby` (the Label, without a name of its own), `aria-orientation`, `aria-disabled`, `data-orientation`, `data-index`, `data-dragging`, `data-disabled`; structural inline style placing it |

## Keyboard

| key | action |
| --- | --- |
| ArrowRight, ArrowUp | + `step` (ArrowLeft in RTL) |
| ArrowLeft, ArrowDown | − `step` (ArrowRight in RTL) |
| Page Up / Page Down, Shift+Arrow | ± `largeStep` |
| Home / End | the lowest / highest value the thumb can reach |
| Tab | the next thumb, in value order |
