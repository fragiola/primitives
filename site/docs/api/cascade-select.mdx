title: CascadeSelect
description: Choose one path through a tree of options from a button whose popup shows one listbox per level, with Menu's submenu keys and hover, and form support.
---

Choose **one path** through a tree of options (a region, then a country, then a city) from a
button whose popup shows one list per level, side by side. It works in a native `<form>` as a
[Select](/docs/api/select) does: it submits, resets and validates.

The APG has no cascading pattern and Base UI has no CascadeSelect. The APG-closest shape is taken:
the APG [select-only combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-select-only/)
(a [Select](/docs/api/select)) whose popup holds **one `listbox` per open level**; the levels open
and close as the APG menu's submenus do (Right opens, Left closes, mirrored in RTL), with
[Menu](/docs/api/menu)'s hover delay and safe area. Zag's and Ark's cascade select and Ant
Design's Cascader were read for the behaviour, never copied.

## Behaviour

- **The value is a path**: the values from the first level down (`["europe", "france", "paris"]`),
  `[]` when nothing is chosen.
- **The tree is `items`** (required): `{ value, label, disabled?, children? }[]`, the toolkit's
  `CascadeItem`. An item with children is a **parent**, else a **leaf**.
- **One Level per depth**: render a Level for each depth of your tree; a Level hands its items
  (the first level's, or the children of the item open at the depth above) to its content, which
  renders an Item per entry. A Level whose depth is not open is `hidden`.
- **The levels and the highlight**: the highlight moves within one level; moving it closes the
  levels below. A keyboard highlight never opens a level by itself: Right (or Enter, Space) does,
  as in the APG menu. Hovering a parent for 100 ms opens its level, the highlight staying on it.
- **Safe area**: while the pointer moves from a parent whose level is open toward that level,
  crossing sibling items does not highlight them nor close the level (Menu's).
- **Choosing**: a leaf is chosen by Enter, Space, Tab or a click, and the popup closes. A parent
  opens its level and is not chosen; with **`changeOnSelect`**, Enter, Space and a click also
  choose the path up to it and the popup stays open on it, so the user can go on. A disabled item
  can be highlighted but is never chosen, and a disabled parent never opens its level.
- **Focus**: DOM focus always stays on the Trigger; the highlighted item is announced with
  `aria-activedescendant`.
- **A parent option** says it opened a level with `aria-controls` (an `option` may not carry
  `aria-expanded` nor `aria-haspopup`), and the deeper Level is named by its parent
  (`aria-labelledby`). Style it from `data-has-children` and `data-expanded`.
- **Forms**: a hidden input carries `name` and the path joined by `valueSeparator` (`/` by
  default: `location=europe/france/paris`); `required` blocks a submission with no path; a form
  reset returns an uncontrolled CascadeSelect to `defaultValue`. In a [Field](/docs/api/field),
  the Trigger is the field's labelable control.
- **Value** shows the last chosen item's label, or, with `separator`, the labels of the whole path
  joined by it ("Europe / France / Paris" with `" / "`). The labels and the separator are the
  app's text. On the server, the Value shows a `defaultValue`'s labels, read from `items`.

## Anatomy

| part | element | `data-primitives-part` | role |
| --- | --- | --- | --- |
| Root | none | | holds the state; renders the hidden input |
| Trigger | `button` | `cascade-select-trigger` | the `combobox`; keeps DOM focus while open |
| Value | `span` | `cascade-select-value` | the chosen label (or the path's), or the placeholder |
| Portal | none | | moves the Positioner to the end of `body` |
| Positioner | `div` | `cascade-select-positioner` | places the popup below the trigger |
| Popup | `div` | `cascade-select-popup` | the floating container of the levels; the app lays them out |
| Level | `div` | `cascade-select-level` | the `listbox` of one depth; `hidden` while not open |
| Item | `div` | `cascade-select-item` | an `option`: a parent or a leaf |
| ItemIndicator | `span` | `cascade-select-item-indicator` | rendered only while its Item is on the chosen path |
| (hidden input) | `input` | `cascade-select-input` | rendered by the Root; what the form submits and validates |

## Usage

<Framework name="react">

```tsx
import { CascadeSelect, type CascadeItem } from "@fragiola/primitives-react/cascade-select";

<CascadeSelect.Root items={LOCATIONS} name="location">
    <CascadeSelect.Trigger aria-label="Location">
        <CascadeSelect.Value placeholder="Choose a place" separator=" / " />
    </CascadeSelect.Trigger>
    <CascadeSelect.Portal>
        <CascadeSelect.Positioner>
            <CascadeSelect.Popup className="flex">
                {[0, 1, 2].map((depth) => (
                    <CascadeSelect.Level key={depth} depth={depth}>
                        {(items: readonly CascadeItem[]) =>
                            items.map((item) => (
                                <CascadeSelect.Item key={item.value} value={item.value}>
                                    {item.label}
                                    <CascadeSelect.ItemIndicator>✓</CascadeSelect.ItemIndicator>
                                </CascadeSelect.Item>
                            ))
                        }
                    </CascadeSelect.Level>
                ))}
            </CascadeSelect.Popup>
        </CascadeSelect.Positioner>
    </CascadeSelect.Portal>
</CascadeSelect.Root>;
```

</Framework>

<Framework name="vue">

```vue
<template>
    <CascadeSelect.Root v-model:value="location" :items="LOCATIONS" name="location">
        <CascadeSelect.Trigger aria-label="Location">
            <CascadeSelect.Value placeholder="Choose a place" separator=" / " />
        </CascadeSelect.Trigger>
        <CascadeSelect.Portal>
            <CascadeSelect.Positioner>
                <CascadeSelect.Popup class="flex">
                    <CascadeSelect.Level v-for="depth in [0, 1, 2]" :key="depth" :depth="depth" v-slot="{ items }">
                        <CascadeSelect.Item v-for="item in items" :key="item.value" :value="item.value">
                            {{ item.label }}
                            <CascadeSelect.ItemIndicator>✓</CascadeSelect.ItemIndicator>
                        </CascadeSelect.Item>
                    </CascadeSelect.Level>
                </CascadeSelect.Popup>
            </CascadeSelect.Positioner>
        </CascadeSelect.Portal>
    </CascadeSelect.Root>
</template>
```

`CascadeSelect` comes from `@fragiola/primitives-vue/cascade-select`; a Level's default scoped
slot gets `{ items }`.

</Framework>

<Framework name="angular">

```ts
@Component({
    imports: [CascadeSelectRoot, CascadeSelectTrigger, CascadeSelectValue, CascadeSelectPortal, CascadeSelectPositioner, CascadeSelectPopup, CascadeSelectLevel, CascadeSelectItem, CascadeSelectItemIndicator],
    template: `
        <ng-container cascadeSelectRoot [items]="locations" name="location" [(value)]="location">
            <button cascadeSelectTrigger aria-label="Location">
                <span cascadeSelectValue placeholder="Choose a place" separator=" / "></span>
            </button>
            <ng-container *cascadeSelectPortal>
                <div cascadeSelectPositioner>
                    <div cascadeSelectPopup class="flex">
                        @for (depth of depths; track depth) {
                            <div cascadeSelectLevel [depth]="depth" #level="cascadeSelectLevel">
                                @for (item of level.items(); track item.value) {
                                    <div cascadeSelectItem [value]="item.value">
                                        {{ item.label }}
                                        <span *cascadeSelectItemIndicator>✓</span>
                                    </div>
                                }
                            </div>
                        }
                    </div>
                </div>
            </ng-container>
        </ng-container>
    `,
})
export class LocationPicker {
    protected readonly locations = LOCATIONS;
    protected readonly depths = [0, 1, 2];
    protected readonly location = signal<readonly string[]>([]);
}
```

A Level's items come from its `items()` signal, through `exportAs`
(`#level="cascadeSelectLevel"`). `(valueChangeDetails)` adds the reason to the two-way `[(value)]`.

</Framework>

## Props

Every part also takes what the [primitive contract](/docs/concepts/primitive-contract) gives:
`render` (Vue: `as` and the `render` slot), a class and a style, a ref, and any attribute, which
it forwards. The names below are React's; Vue binds them the same way (`v-model:value`,
`v-model:open`), and Angular as inputs and outputs (`[(value)]`, `(valueChangeDetails)`).

### Root

| prop | type | default | description |
| --- | --- | --- | --- |
| `items` | `{ value, label, disabled?, children? }[]` | | required: the tree |
| `value` | `string[]` | | the chosen path, controlled |
| `defaultValue` | `string[]` | `[]` | the initial path, uncontrolled |
| `onValueChange` | `(value: string[], details: { reason }) => void` | | every change (`item-press`, `focus-out` for Tab, `none` on a form reset) |
| `changeOnSelect` | `boolean` | `false` | a parent can be chosen too (Enter, Space, a click), the popup staying open |
| `name` | `string` | | the hidden input's name (a field's wins) |
| `required` | `boolean` | `false` | the form cannot submit with no path |
| `disabled` | `boolean` | `false` | the trigger opens nothing |
| `valueSeparator` | `string` | `"/"` | joins the path in the hidden input |
| `open` | `boolean` | | the open state, controlled |
| `defaultOpen` | `boolean` | `false` | the initial open state |
| `onOpenChange` | `(open: boolean, details: OpenChangeDetails) => void` | | every open change, with its reason; called before the change, `details.cancel()` stops it |
| `onOpenChangeComplete` | `(open: boolean) => void` | | once an opening or a closing has finished its transitions |
| `actionsRef` (react) | `{ current: OverlayActions \| null }` | | receives `close()` and `unmount()`; Vue exposes them on the Root's template ref, Angular as the root directive's methods |

### Trigger

No props of its own.

### Value

| prop | type | default | description |
| --- | --- | --- | --- |
| `placeholder` | `ReactNode` | | shown while nothing is chosen |
| `separator` | `string` | | joins the labels of the whole path; without it, the last chosen label |

### Portal

| prop | type | default | description |
| --- | --- | --- | --- |
| `container` (react, vue) | `Element` | `document.body` | where the Positioner goes |
| `keepMounted` (react, vue) | `boolean` | `false` | keep the content rendered while closed, `hidden` and `data-closed` |
| `options` (angular) | `Element \| { container?, keepMounted? }` | `{}` | the same two options: `*cascadeSelectPortal="{ keepMounted: true }"` |

### Positioner

| prop | type | default | description |
| --- | --- | --- | --- |
| `side` | `"top" \| "bottom" \| "inline-start" \| "inline-end" \| "left" \| "right"` | `"bottom"` | the side of the trigger |
| `align` | `"start" \| "center" \| "end"` | `"start"` | the alignment along that side |
| `sideOffset` | `number` | `4` | the distance from the trigger, in px |
| `alignOffset` | `number` | `0` | the shift along the trigger's edge, in px |

| prop | type | default | description |

## State and part attributes

| part | attributes |
| --- | --- |
| Trigger | `role="combobox"`, `type="button"`, `aria-haspopup="listbox"`, `aria-expanded`, `aria-controls` (the open Levels, while open), `aria-activedescendant` (the highlighted item, while open), `aria-required`, `disabled`, `data-popup-open`, `data-placeholder`, `data-disabled`; in a Field, the field's states |
| Value | `data-placeholder` |
| Positioner, Popup | as the [Select](/docs/api/select)'s |
| Level | `role="listbox"`, `data-depth`; the first level `aria-labelledby` the Trigger's labels, a deeper one its parent option; `hidden` while not open |
| Item | `role="option"`, `aria-selected` (on the chosen path at its depth), `aria-disabled`, `data-highlighted`, `data-selected`, `data-disabled`, `data-has-children` (a parent), `data-expanded` and `aria-controls` (its children's Level) while its level is open |
| ItemIndicator | `aria-hidden="true"` |
| hidden input | `name`, `value` (the path joined by `valueSeparator`), `required`, `disabled`, `aria-hidden="true"`, `tabindex="-1"` |

## Keyboard

DOM focus stays on the Trigger. "Inline-end" is Right in LTR and Left in RTL.

| key | closed | open |
| --- | --- | --- |
| ArrowDown, ArrowUp, Enter, Space | opens on the chosen path (every level of it open), else on the first enabled item | ArrowDown / ArrowUp: the next / previous item of the level; Enter / Space: chooses a leaf, opens a parent (and chooses it with `changeOnSelect`) |
| Home / End | opens on the first / last item of the first level | the first / last item of the level |
| inline-end (Right in LTR) | | on an enabled parent: opens its level on its first enabled item |
| inline-start (Left in LTR) | | in a deeper level: closes it and highlights its parent |
| a printable character | opens on the first item of the first level whose label starts with the text | typeahead within the level |
| Escape | | closes without choosing |
| Tab | moves on | chooses the highlighted item when it can be chosen, closes and moves on |
